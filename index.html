The twelve wings

How it is built

One HTML file, no build step, no tracking. Three.js draws all 88 plaques, frames, plinths and floor lights in a handful of instanced draw calls, and the renderer sleeps whenever the room is still — the plan view below mirrors the exact geometry the GPU sees.

The plan view is clickable: pick a wing to send the camera there. Favourites live in this browser only (localStorage), nothing leaves the page.
